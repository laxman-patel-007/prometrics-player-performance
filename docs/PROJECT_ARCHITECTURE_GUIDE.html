2. File-by-File Technical Deep Dive

2.1 User Interface & Application Layer

app.py — Production Streamlit 6-in-1 War Room Dashboard

WHAT The primary web application serving as the interactive decision-support war room for franchise executives, coaches, and sports data analysts (990+ lines of Python).

HOW Uses Streamlit, Plotly Express/Graph Objects, and Pandas. Utilizes @st.cache_data and @st.cache_resource to load dataset and 13 ML models into RAM. Organizes intelligence across 6 modules: War Room & Roster Intel, Telemetry & Factor Impact (radar charts and correlations), AI Rating & Auction Valuation (sliders, presets, purse calculator), Tactical Archetypes & 2D Map (PCA coordinates and K-Means clusters), What-If Simulator, and Model Benchmarks & Defense.

WHEN Continuously executed in real-time when accessed locally (localhost:8501) or hosted on Streamlit Community Cloud.

WHY Bridges complex machine learning algorithms and executive decision-makers. Franchise directors require real-time visual scenario analysis rather than command-line outputs.

.streamlit/config.toml — Theme & Server Configuration

WHAT Streamlit configuration file defining visual design tokens, server ports, and client error handling.

HOW Configures primaryColor to franchise gold (#F59E0B), backgroundColor to dark slate (#0F172A), secondaryBackgroundColor to navy (#1E293B), and sets showErrorDetails = true.

WHEN Automatically read by Streamlit at server initialization before app script execution.

WHY Enforces consistent enterprise dark-mode branding across all devices regardless of user browser defaults.

2.2 Data Ingestion & Pipeline Layer

src/cricket_data_pipeline.py — Delivery Aggregator & Feature Engine

WHAT Data ingestion and transformation script aggregating 260,920 raw deliveries into 619 qualified player profiles with 27 engineered metrics.

HOW Parses deliveries_2008_2024.csv and matches_2008_2024.csv. Calculates batting averages, strike rates, death overs (16–20) strike rates, bowling economies, dot ball percentages, and joins Player of the Match awards. Filters players with minimum 3 matches, computes composite indices, and serializes clean CSV output.

WHEN Executed when updating the database with new match data or re-engineering feature definitions (python src/cricket_data_pipeline.py).

WHY Transforms unstructured granular ball logs into clean, normalized tabular ML vectors.

data/processed/cricket_players_clean.csv — Qualified Analytical Dataset

WHAT Structured CSV dataset of 619 qualified professional cricketers across 32 columns (150 KB).

HOW Contains 25 numerical metrics, primary role labels, performance ratings, tier codes, and auction values.

WHEN Loaded by app.py during web dashboard runtime and by train_cricket_models.py during training.

WHY Lightweight footprint (150 KB) ensures instant git pushes and sub-second container cold-boots on Streamlit Cloud.

data/raw/matches_2008_2024.csv — Match Metadata

WHAT Match summaries for all 1,095 IPL matches played from 2008 to 2024 (218 KB).

HOW Contains match dates, venues, participating teams, toss decisions, winners, and Player of the Match awardees.

WHEN Ingested by cricket_data_pipeline.py to join match-winning awards.

WHY Player of the Match awards provide empirical evidence of clutch resilience under tournament pressure.

data/raw/deliveries_2008_2024.csv — Ball-by-Ball Logs

WHAT Granular ball-by-ball delivery event logs covering 260,920 deliveries across 17 IPL seasons (69 MB).

HOW Contains over-by-over batsman runs, bowler names, dismissals, and extra runs.

WHEN Processed once by the data pipeline script. Ignored by .gitignore to keep git repositories fast and lean.

WHY Necessary to compute granular phase-specific metrics (death overs strike rate) not found on standard season scorecards.

2.3 Machine Learning Pipeline & Serialized Models

src/train_cricket_models.py — Model Training & Governance Script

WHAT Training script that trains, validates with 5-fold cross-validation, and serializes all 13 ML models.

HOW Executes one-hot encoding, stratified 80/20 train/test split, standard scaling, trains 5 regressors (Linear, Ridge, Poly, RF, MLP), trains 5 classifiers (KNN, RF, Logistic, Decision Tree, MLP), trains K-Means (k=5) and PCA, and dumps all artifacts to models/ via joblib and JSON.

WHEN Executed during offline model training cycles (python src/train_cricket_models.py).

WHY Centralizes model training and governance into a deterministic, reproducible, audited script.
